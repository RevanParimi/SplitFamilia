# SF-006 — New groups get a code that strangers can't guess

Priority: **P0** · Task: **T-02** (story 5 of 5) · Estimate: **3 points**

Status lives in [STATE.json](../STATE.json), not in this card. Dependencies: SF-005. Owner
decisions: **D-4** (see `open_decisions` in STATE).

Brief: [stage 1 (security) and stage 4 (Data Safety: user data must be handled
securely)](../brief/2026-09-28-google-play-release-brief.md).

## Intended result

Starting a new group called "goa trip" creates a code like `goa-trip-7k2m9xqpwd`. Nobody can land
in the group just by guessing its name, because joining needs the invite link or the full code.
Groups that already exist keep working from their old links and exact names, so today's family
ledger is not lost.

Why: today, whoever types the same name, for example `goa-trip-2026`, lands in the same group and
can read and change everyone's names and expenses. That is acceptable for one family and not for
a public Play Store app.

## Starting points

- `index.html`: the join screen (lines 373–385), the join handler (lines 508–519), "Copy invite
  link" (lines 528–539), and `slugify()` (line 486).
- The group-ID pattern from SF-005.

## Acceptance criteria

- The join screen offers "Start a new group" (a name) and "Join with a link or code" (a pasted
  invite URL or a code).
- A new group's ID is `slugify(name)` + `-` + at least 10 random characters from a 32-character
  lowercase alphabet (about 50 bits), drawn from `crypto.getRandomValues`, never `Math.random`.
  The whole ID fits the SF-005 pattern.
- "Join" accepts a full invite URL (it reads `g`) or a bare code. Invalid input shows the SF-005
  message.
- When online, joining a code that has no people, no expenses and no group document shows "No
  group found with that code" instead of quietly creating an empty group. When offline, it
  explains that it can't check yet.
- Existing IDs without a suffix still open from their links and by typing the exact old name
  under "Join".
- "Copy invite link" shares the full code.
- Bump the service-worker cache name.

## Required tests

- Pure functions tested with `node --test`:
  - code generation: format, length, alphabet, and whether it matches the SF-005 pattern;
  - with a stubbed random source, a fixed byte sequence → a known code (worked out by hand);
  - invite parsing: `https://host/index.html?g=goa-trip-7k2m9xqpwd` → `goa-trip-7k2m9xqpwd`;
    bare code → the same; `https://host/?x=1` → invalid.
- Manual browser check: start a group, copy the link, open it in a private window → the same
  ledger. Join a made-up code → "No group found".
